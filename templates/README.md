# Blog post template

`blog-post.html` captures the site shell and expanded article layout used by “What pages should a construction company website have?” It is a starting point for future posts, not a published page.

Copy it into a new root-level slug directory as `index.html`, replace every `{{PLACEHOLDER}}`, and keep the contents links and section IDs in sync. Use unique, accurate copy and metadata, a real publication date, relevant internal links, and only substantiated claims. Add the new canonical URL to `sitemap.xml` and a listing to `blog/index.html`. Verify the page, links, and structured data before publishing.

The published pages are static copies: shared header, footer, and styling changes must be applied to the template and existing pages when appropriate.
